# 🌸 Web A25 — Satu Foto, Sejuta Kenangan

Website **Web A25** dibuat sebagai ruang kenangan untuk Angkatan 25 A2.  
Bukan hanya sekadar website foto, tapi tempat untuk mengingat cerita, tawa, kebersamaan, dan perjalanan yang pernah kita lewati bersama.

## ✨ Tentang Website

Web ini dibuat dengan nuansa romantis, hangat, dan penuh nostalgia.  
Saat pengunjung membuka website, mereka akan diajak untuk melihat satu foto yang kemudian membawa mereka ke banyak kenangan indah bersama keluarga besar A25.

> “Dari satu foto, lahir sejuta kenangan.”

## 🎯 Tujuan

Website ini dibuat agar tali persaudaraan A25 tetap kuat, meskipun waktu terus berjalan dan jalan hidup kita mungkin berbeda.

A25 bukan hanya angkatan.  
A25 adalah cerita, keluarga, dan kenangan yang akan selalu hidup.

## 🛠️ Teknologi yang Digunakan

Project ini kebanyakan menggunakan:

- **CSS** — untuk tampilan, animasi, warna, layout, dan efek visual
- **JavaScript** — untuk interaksi klik dan efek muncul foto
- **HTML** — sebagai struktur utama halaman

## 🎨 Bahasa Project

- CSS: 55.8%
- JavaScript: 25.9%
- HTML: 18.3%

## 💖 Fitur Utama

- Tampilan romantis dan estetik
- Efek klik untuk membuka kenangan
- Galeri foto penuh nostalgia
- Animasi halus dan menarik
- Desain responsive untuk HP dan laptop
- Quotes persaudaraan dan kenangan A25

## 🤝 Makna Project

Website ini dibuat untuk mengingat bahwa kebersamaan tidak akan hilang hanya karena waktu.  
Selama kita masih mengingat, A25 akan tetap hidup.

Semoga website ini menjadi tempat kecil untuk menyimpan rasa rindu, cerita lama, dan semangat persaudaraan.

## 🌷 Pesan untuk A25

Terima kasih untuk semua kenangan.  
Untuk tawa, cerita, perjuangan, dan kebersamaan yang pernah kita bangun.

Semoga tali persaudaraan A25 tetap kuat sampai kapan pun.

**A25 bukan sekadar nama.  
A25 adalah keluarga.**
