# 🙌 Web A25 — Satu Foto, Sejuta Kenangan

Website **Web A25** dibuat sebagai ruang kenangan untuk Angkatan 25 A2.  
Bukan hanya sekadar website foto, tapi tempat untuk mengingat cerita, tawa, kebersamaan, dan perjalanan yang pernah kita lewati bersama.

---

## ✨ Tentang Website

Web ini dibuat dengan nuansa **romantis, hangat, dan penuh nostalgia**.  
Saat pengunjung membuka website, mereka akan diajak melihat satu foto yang kemudian berkembang menjadi banyak kenangan.

> 💭 *"Dari satu foto, lahir sejuta kenangan."*

---

## 🎯 Tujuan

Website ini dibuat agar tali persaudaraan A25 tetap kuat, meskipun waktu terus berjalan.

A25 bukan hanya angkatan.  
A25 adalah **cerita, keluarga, dan kenangan yang akan selalu hidup.**

---

## 🛠️ Teknologi yang Digunakan

Project ini dibangun menggunakan:

- 🎨 **CSS** — tampilan, animasi, warna, dan efek visual
- ⚡ **JavaScript** — interaksi klik & efek muncul foto
- 🧱 **HTML** — struktur utama halaman

---

## 📊 Bahasa Project

- CSS: **55.8%**
- JavaScript: **25.9%**
- HTML: **18.3%**

---

## 💖 Fitur Utama

- Tampilan romantis & estetik  
- Efek klik untuk membuka kenangan  
- Galeri foto penuh nostalgia  
- Animasi halus & interaktif  
- Desain responsive (HP & Laptop)  
- Quotes persaudaraan A25  

---

## 🤝 Makna Project

Website ini dibuat untuk mengingat bahwa kebersamaan tidak akan hilang hanya karena waktu.  
Selama kita masih mengingat, A25 akan tetap hidup.

Semoga website ini menjadi tempat kecil untuk menyimpan rasa rindu, cerita lama, dan semangat persaudaraan.
